## Core Workflow

```text
Edit files
    ↓
git status / git diff
    ↓
git add
    ↓
git commit
    ↓
git push
    ↓
GitHub
```

## Why Git Matters for Data Engineering

Git helps me:

- track changes in data engineering projects
- work safely with branches
- collaborate with other developers
- manage ETL, pipeline, SQL, and infrastructure code
- review and restore previous versions
- keep a reliable history of project development
